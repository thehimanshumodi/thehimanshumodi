## 🚀 Featured Projects

### 🤖 [ML Knowledge Assistant — RAG-Based AI System](https://github.com/thehimanshumodi)
> An intelligent Q&A system that answers Machine Learning queries using Retrieval-Augmented Generation

- 🔍 **Semantic Search** via FAISS vector database for efficient document retrieval
- 🧠 **Groq LLM** integration for context-aware, low-latency responses
- 🛡️ Reduced hallucination by combining retrieval + LLM generation
- ☁️ Deployed live on **Streamlit Cloud**
- ⚙️ **Tech:** Streamlit · LangChain · FAISS · Groq LLM · Python

---

### 🎯 [ResumeIQ — NLP-Powered Resume Analyzer](https://github.com/thehimanshumodi/Resume-Analyzer)
> AI tool that matches resumes with job descriptions and identifies skill gaps

- 🏷️ **NER Extraction** using spaCy — skills, education & organizations
- 📐 **TF-IDF + Semantic Similarity** via Sentence Transformers (`all-MiniLM-L6-v2`)
- 📊 **Skill Gap Analysis** with personalized recommendations
- ☁️ Deployed live on **Streamlit Cloud**
- ⚙️ **Tech:** Python · spaCy · Sentence Transformers · scikit-learn · Streamlit

---
